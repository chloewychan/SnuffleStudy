# SnuffleStudy V4.1 Scope Summary — Sidebar Reformat

**Purpose of this document:** the definite v4.1 scope — a reformat of the existing sidebar in preparation for a later visual design pass, not a redesign itself. This document states what gets built, not why — drawbacks and alternatives were discussed and resolved before this was written. Deeper backend/dead-code cleanup that this reformat makes possible (removing now-unused tables, columns, and message handlers once their UI is gone) is tracked separately as v4.2 and is not part of this scope.

The full-tab Options page (`OptionsApp.tsx`, opened via `chrome://extensions` or the sidebar's Log-In button) is explicitly left untouched this version. It keeps its own Settings/History/Account/Friends/Privacy navigation and keeps composing `AccountPage.tsx`/`FriendsPage.tsx`/`SettingsPage.tsx` as those components exist after this release — since friend management is moved out of `AccountPage.tsx` below, the Options page simply stops offering it. Friend management becomes sidebar-only, by choice.

---

## General

- Onboarding (`OnboardingWizard.tsx`) keeps only the "Welcome to SnuffleStudy" screen (`WelcomeScreen.tsx`) and the existing sign-in step. The Meet Snuffles, Choose a pressure style, Default study duration, How should Snuffles track distraction, Set a hard-block passcode, and Ready to go steps are removed.
- Finishing onboarding writes fixed defaults instead of collecting them: 25-minute focus duration, Activity-only tracking, Soft restriction mode, and Gentle Encouragement pressure style. The first three already match `DEFAULT_USER_SETTINGS`; the pressure-style default changes from today's `strict-coach` to `gentle-encouragement`. Tracking permission and a hard-block passcode are left for the user to set later, in Settings.
- The popup (`PopupApp.tsx` and its manifest wiring) is removed entirely — the side panel is the only UI.
- Every literal `"E.g., …"` placeholder gets its adjacent action button disabled while that field is empty. This convention also applies to every new field introduced by this release (the new restricted-site field, the new written-nudge field).
- Every section's own Refresh button is removed in favor of one Refresh button in the Header that re-runs every mounted panel's own fetch.

---

## New Footer (global, persistent)

Not a tab — a region that renders beneath the tab content, mounted once at the app-shell level (a sibling of `Header.tsx`, not inside any per-tab conditional), so it stays mounted across tab switches and through the active-session view. It stacks up to two independent pieces, in order: the Study Room footer, then the Nudges & Unlock Requests footer beneath it when either has something to show. Their contents are specified under "Other Pages" below.

This requires lifting the study-room state that `StudyRoomPanel.tsx` currently owns locally — the joined-room state, video tiles, participants, and the LiveKit connection — out of that tab-scoped component into shared, always-mounted state. Today, that component's cleanup effect calls `videoCallClient.leaveCall()` on unmount, and it currently only exists while its tab is mounted; a persistent footer needs the join/leave lifecycle to survive a tab switch instead of tearing down the call.

## Bunny Tab

- Remove the "Show Bunny" toggle.
- Replace the single Save button with two independent ones — Save bunny name and Save human name — each disabled/loading only for its own field. Both still save through the existing `PROFILE_SAVE_MINE` message.
- Remove the Status box (Happiness / Productivity / Friendliness meters) entirely.

---

## Study Tab

- Seed a task titled "Study with Snuffles" for every new account.
- Task Vault: replace each item's Delete button with a checkbox that marks the task done, wired to the `Task.completedAt` field and the `TASK_UPDATE` message — both already exist and are already unused by any current UI, so no new backend is needed here.
- Task Vault: completed tasks sink to the bottom of the list; uncompleted tasks stay on top, in their existing order.
- Default the session setup form's Goal select to the first task in the list — since completed tasks are now at the bottom, that's the first uncompleted task. For a brand-new account, that's "Study with Snuffles."
- Rename the restriction-mode option in the session setup form from "Soft - nudge & escalate" to plain "Soft."
- Move the Study Rooms box in from the Friends tab — the list-browsing/create/manage-access view only. The joined-room view is the new global Study Room footer, not part of this tab.
- Study Rooms box: room list items become click-to-select (single selection) instead of each carrying its own Join button. One "Join study room" button joins whichever room is currently selected.
- Move "Archive this room" inside Manage access, alongside the friend-invite list — both stay hidden until Manage access is opened, same as today.

---

## Friends Tab

The current "Friend activity" panel (event feed, daily digest, nudge picker, incoming audio nudges) is fully dismantled: some of it is removed outright, the rest splits into two new boxes or moves into the global footer.

- Remove the Study Rooms box from this tab (now on Study).
- Remove the daily-digest section and the generic friend-activity event feed from the UI.
- Remove the standalone Friend requests box — its contents move into the Nudges & Unlock Requests footer.
- Remove the incoming-nudge overlay card from this tab — it moves into the same footer, which stays visible by default whenever there's an undismissed nudge, regardless of active tab or session state.
- **New Friends box:**
  - A multi-select checklist of the user's friends (moved from Settings → Account's "Your friends"), each row with an "options" button.
  - A Nudge button plus a dropdown of every item in the Nudge Vault (below); sends the chosen nudge to every selected friend, then deselects them.
  - An "Add to room" button plus a dropdown of the user's study rooms; adds every selected friend to the chosen room (via the existing `STUDY_ROOM_INVITEE_ADD` message, called once per selected friend), then deselects them.
  - "Add a friend" and "Invite a friend," moved in from Settings → Account.
  - Per-friend options popover: the seven sharing checkboxes reused from the existing per-friend settings page (send/receive live nudges; share distraction attempts, current site, goal text, intervention count, full history) — the "Receive a daily digest about this friend" checkbox is dropped along with the rest of the digest feature — followed by a "Remove friend" button.
- **New Nudge Vault box**, replacing "Friend activity": top half is a record-a-new-audio-nudge button plus a list of the user's own saved audio nudges; bottom half is a textbox with an Enter/submit action to add a written nudge, plus a list of the user's own saved written nudges. Every item, audio or written, has its own delete button. This is new storage and new messages for both nudge types — today's nudges are either a fixed catalog (`NUDGE_MESSAGES`, written) or one-off audio clips tied immediately to a send action, with no "record or write it, keep it, reuse it, delete it later" library for either type. The Nudge Vault is the source both for this box's own lists and for every "pick a nudge to send" dropdown elsewhere (the Friends box above, the Study Room footer below).

## Settings

Applies to the sidebar's Settings tab. The full-tab Options page keeps its own separate navigation, per the note at the top of this document.

- Replace the Settings/Account/Friends/History sub-navigation with one scrolling view of section boxes, matching every other tab's layout. The Friends destination is dropped entirely — its content now lives in the Friends tab's per-friend options popover.
- **General box:** remove the "generic session events sync…" paragraph, the "these only control whether THIS device shows a toast…" paragraph, and the "share this with a friend, not with yourself…" passcode paragraph. Replace the "default restricted sites" textarea with a text field and Submit button, plus a list of already-added sites, each with its own delete button. Add a "Confirm new passcode" field — require both to match before the passcode can be changed.
- **Account box:** remove the password section's descriptive paragraph and the delete-account section's descriptive paragraph. Put Sign out and Delete account side by side under one Account heading, dropping the separate Delete-account section wrapper (the existing inline confirmation step still appears once triggered). Move Invite a friend, Add a friend, and Your friends out to the new Friends-tab box.
- **History box:** inline the existing History page content directly as a box in this same view.

## Other Pages — Study Session

Two new footers, stacking in this order when both apply: Study Room, then Nudges & Unlock Requests beneath it.

### Study Room footer

- Remove the plain participant-name list — every participant already has a tile (webcam video, or a name-only rectangle when the camera is off).
- Make each tile selectable (click to toggle) — a new interaction; tiles are display-only today.
- Add one Nudge button plus a dropdown of current Nudge Vault items; sends the chosen nudge to every selected participant.
- Remove the ability to record a producer tag from inside the room. Sending a saved Nudge Vault audio item via the new Nudge button covers the in-room-audio case instead.
- Requires the persistent, app-shell-level mount described under "New Footer" above.

### Nudges & Unlock Requests footer

- Per incoming nudge: the sender, its content (an audio player or the written text), and a Dismiss button.
- Per incoming unlock/friend request: the requester, what they're requesting, their optional message, an X to deny, and a check to accept.
- Mounted alongside the Study Room footer, always available regardless of active tab or session state — it stays visible by default while anything is undismissed.
- This is a relocation of logic that already works (the friend-requests panel's approve/deny flow, and the incoming-nudge dismiss flow) into a persistent, always-mounted presentation — no backend changes needed.

---

## Definition of done for V4.1

Onboarding is one screen plus sign-in; every other setting it used to collect is a fixed default the user can change later in Settings. There is no popup — the side panel is the only UI, with one Refresh button in its header instead of one per section. The Bunny tab has two independent name-save buttons and no toggle or status box. The Study tab seeds a first task, defaults a new session's goal to the first uncompleted task, and folds in the Study Rooms list/create/manage-access box, whose joined-room view now lives in a persistent footer that survives tab switches instead of unmounting. The Task Vault marks tasks done with a checkbox instead of deleting them, sinking completed ones to the bottom. The Friends tab centers on two new boxes — a multi-select friends list with bulk nudge-and-room actions and a per-friend options popover, and a Nudge Vault of the user's own saved audio and written nudges — with the old activity feed, daily digest, and standalone friend-requests box gone. Settings is boxes, not tabs, with friend management relocated to the Friends tab and the Options page's own navigation left exactly as it was. A Study Room footer and a Nudges & Unlock Requests footer are both mounted globally, visible regardless of tab, replacing their old tab-scoped presentations with logic that's otherwise unchanged.
