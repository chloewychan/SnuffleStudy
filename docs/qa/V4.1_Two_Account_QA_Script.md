# SnuffleStudy V4.1 Two-Account QA Script

**Purpose:** the manual QA pass for `docs/implementation_plans/V4.1_Implementation_Plan.md`'s
Task 11 — this is a **UI reformat** release ("restructuring and defaulting, not a redesign," per
`docs/scope_summaries/V4.1_Scope_Summary.md`), not a new backend surface, so this script is
deliberately lighter than `V3.2_Two_Account_QA_Script.md`/`V3.4_Two_Account_QA_Script.md`: no Edge
Function redeploys, no four-account setup, no cooldown/rate-limit torture testing. It's still a
**human step** — no agent session should attempt to execute this script or sign into anything.

**What's already verified and does NOT need re-checking here:** `docs/reports/v4.1/task-11-
report.md` covers the full programmatic pass — clean `tsc`, 891/891 tests, a clean production
build, and the one real backend gap this version's Task 11 found (`delete_account_data()` missing
a `nudge_vault_texts` cleanup clause) is fixed and confirmed live. This script is UI-only: does the
reformatted sidebar actually work the way the scope doc describes, with two real accounts clicking
through it.
